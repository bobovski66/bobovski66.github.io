MODEL / VERSION 01.1

  

    
A local statistical ecology
Each bump is a normalized Gaussian spatial distribution carrying a categorical predictor. Its communication history changes that predictor. Its spatial shape and location adapt under the Fisher metric.

    
State and spatial geometry

    
Agent i has qi(x,a) = 𝒩(x; μi, σi²I) πi(a). Every Gaussian has unit mass. Its peak therefore changes when its width changes. The displayed field is the sum of these densities, colored by their local signal composition, sampled on a display grid and tone mapped.

    
ds² = |dμ|² / σ² + 4(dℓ)² + Σa (dπa)² / πa,   ℓ = log σ.

    
The support is the Euclidean plane. A weak eighth-power confinement potential keeps agents near the viewing region. Communication and pair interactions use w(r) = (1 − r²/R²)³ for r < R, and zero otherwise. This cutoff is C². For spatial adaptation, all derivatives of the cutoff are included.

    
The pair energy is w(r)[b exp(−r²/(2r₀²)) − a Bij], with r₀ = 0.24 and the exact Gaussian Bhattacharyya affinity

    
Bij = [2σiσj / S] exp(−r² / 4S),   S = σi² + σj².

    
Add κ(ℓ − log σ₀)²/2 per agent and U(μ) = (0.4/8)[(x/5)⁸ + (y/3.15)⁸]. The Fisher spatial flow is μ̇ = −mσ²∇μE and ℓ̇ = −(m/4)∂ℓE. The adaptive explicit integrator uses an Armijo backtracking check; accepted spatial steps descend in E while parameters remain fixed. Logged width keeps σ positive. Freezing width restricts the flow to the fixed-width submanifold.

    
Messages, prediction, and provenance

    
A candidate channel exists when w(r) ≥ 0.025 and the message rate is positive. The loop calibration uses only the declared arrows A → B → C → A. Each admitted directed link has a Poisson emission count of mean λw(r)Δt in each integration interval. The sender samples a signal type from its current π. Channel noise changes it to a uniformly chosen different type with probability ε.

    
Packets are addressed to agents. Membership is checked at emission; their latency is τ + r/c, using distance at emission. Packets already in flight still arrive when agents move or controls change. This is a local delayed graph channel with distance-dependent latency. Deliveries are processed in scheduled order at integration boundaries, at most 0.04 simulation seconds after their due time. The model does not impose a continuous-space wave equation.

    
A received type y has loss −log π(y). The exact categorical natural-gradient flow during exposure η gives

    
π⁺ = e−ηπ⁻ + (1 − e−η)ey.

    
Surprise is −log π⁻(y). State change is DKL(π⁺ ∥ π⁻). Next-message gain evaluates the current prediction against the state immediately before the previous message, on the new message. Intervening background refresh and game dynamics are included in that comparison. These quantities are distinct; the lab does not label them transfer entropy.

    
A pulse changes only its selected source’s emitted types for a finite duration. A separate nonnegative vector records the part of each π inherited from the current pulse. The sender samples ancestry conditionally on the emitted type. A received tagged contribution is added with exactly the same weight as its categorical update. Noise preserves ancestry while possibly changing the type. Thus ancestry is not a measure of signal correctness. A new pulse clears the current ancestry labels; the existing predictive states remain.

    
Background refresh solves π̇ = ε(1/K − π) exactly and adds untagged mass. Optional cyclic activity uses the explicit non-potential replicator game fa = πa+1 − πa−1 for K ≥ 3. It uses a normalized exponential step, rescaling same-type ancestry contributions by the same factor. The spatial potential is independent of type, so grouping does not read another agent’s hidden predictor.

    
Contact realization

    
For qθ = exp(θ · T − ψ), use α = dz − η · dθ and the statistical Legendrian η = ∇ψ, z = ψ. With α(XH) = −H, the Hamiltonian

    
H = (η − ∇ψ) · v(θ,t) + γ(z − ψ)

    
restricts to θ̇ = v on the Legendrian. This lab evolves the invariant slice η = ∇ψ with c = z − ψ and ċ = −γc. It reconstructs η and z from the state and the exactly decaying residual after each update. Received messages induce discrete parameter updates and are lifted by the same reconstruction. This is a diagnostic contact realization of the chosen statistical dynamics, rather than an independent integration of every ambient contact coordinate.

    
The spatial natural parameters are (μx/σ², μy/σ², −1/(2σ²)). Categorical parameters are log(πa/πK) for a < K. Their expectation coordinates are (μx, μy, |μ|² + 2σ², π₁, …, πK−1).

    
Directed topology

    
The inspector chooses the selected agent and up to three nearest agents within its nominal range. It retains every currently admitted directed channel whose endpoints are in that window. This inspection limit does not limit the simulation’s communication.

    
The complex’s vertices are these channels. A collection is a simplex exactly when each receiving agent has at most one incoming selected channel and the selection contains no directed cycle. All faces are enumerated. Boundary ranks and ordinary Betti numbers are calculated exactly over 𝔽₂. The largest inspected window has four agents, so its forests contain at most three edges and its complex has dimension at most two.

    
The three-channel loop has f = (3,3) and β = (1,1). The complete bidirected four-agent graph has f = (12,48,64) and β = (1,0,27). A local window cannot certify the absence of a longer global cycle. Time persistence and spatial Čech complexes are further stages of this project; this version computes snapshot forest homology.

    
Reproducibility

Loading resumes the random stream exactly. Playback speed changes the wall-clock rate; the equations use simulation time. Display controls do not consume randomness. The offline download is self-contained and needs no network connection.
